# Instalar Visu BioGeo

| Dispositivo | Instalación |
|---|---|
| Windows de 64 bits | Ejecuta `output/Instalar Visu BioGeo Windows.exe`. Incluye todas las fotos aprobadas y crea un acceso directo. |
| Mac | Abre la web de Visu; Safari > Archivo > Añadir al Dock, o Instalar en Chrome. |
| iPad / iPhone | Abre la web de Visu en Safari > Compartir > Añadir a pantalla de inicio. |
| Android | Abre la web de Visu en Chrome > Instalar aplicación. |

Web: https://visu-biogeo-santica.nimblequail260.chatgpt.site/

El catálogo web está actualmente en modo público. Si el propietario lo configura como privado, requerirá además el acceso de ChatGPT al sitio. En Ajustes de Visu accede con tu correo y la contraseña de estudio para compartir progreso. Espera a «Sincronizado». Otras personas que tengan una copia del instalador no reciben tu contraseña ni tu sesión, ni están autorizadas en tu base.

Para recuperar el progreso anterior: entra en la cuenta desde el navegador y dirección donde estudiabas y pulsa «Incorporar mi progreso local». Espera a «Sincronizado» antes de cambiar de dispositivo. Guarda también una copia JSON en Ajustes.

Windows incluye el banco de fotos en disco. En móvil, iPad o Mac guarda los bloques deseados en Ajustes antes de estudiar sin Internet. La web completa ocupa más de 1,3 GB y la capacidad de almacenamiento depende del navegador. Las fotos personales añadidas en la interfaz se trasladan mediante copia JSON.
